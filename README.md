# Hi, I'm Jacob
_Sometimes I also go by Alastair._

I'm a 23yo full stack developer with a passion for code as a tool to both play
with and to change the world, learning to code at the ripe old age of 11 (before
that I was having fun pulling apart phones trying to understand what was going on inside) and getting only more passionate with every passing day. Going from
`turtle` in Python to creating my own compiled programming language with ARC
memory management, playing with kernel development and being a part of teams
creating technology used by tens of thousands of people daily across the globe.

I'm a tinkerer, and I love to know how things work and pull them apart 'til I
get the answer I want. In the age of modern LLMs, I try to keep what I can human,
using it as a tool to speed my work up and not a replacement. The foundation
of the modern dev community is first and foremost humans.
 
## Stack

Express (now Koa), React (Next.js) and Node.js - with a touch of React Native
and Expo; not afraid to keep up with the pace of modern software engineering and
try out new technology.

contribute to the [servo](https://github.com/servo/servo) browser engine

I've also taken some minor interest in Go and C++ on the side.
